# 潮汐拼块

6×6 点选摆块。每一手开始前，左潮或右潮已经公开。松块先按这个方向挤齐，棋盘真正改完，排满的行和列才消除。摆下去的那一下不会消线。

没有构建步骤。GitHub Pages 直接提供这个目录。

## 玩法

在仓库根目录：

```bash
python3 -m http.server 8000
```

打开 `http://127.0.0.1:8000/tidal-blocks/`。

和盘面上同一套说法：

- 点手牌里的形状，再点格子。形状从该格向右、向下铺开。不拖动，避免手指挡住格子。
- 一手里的形状要全部摆上，才可以涨潮。顺序可以自己选。
- 左潮把每一行里的松块向左挤齐，右潮向右挤齐。灰桩是锚点，停在原地，并把这一行切成两段；松块不会越过锚点。
- 虚线是同一套压缩规则算出来的落点。点涨潮后，先显示挤齐后的棋盘，再消去因此排满的行和列。排满指没有空格，并且里面至少有一块松块；整列都是锚点的桩墙不会自己消失。线上的锚点会跟着被清掉。
- 消去一条线 100 分，同一次潮汐消去两条或更多再加 50。最佳分按关存在这台设备的 `localStorage`，键名 `tidal-blocks-v1`。
- 撤销退回上一步（摆块或涨潮）。重开只重置当前关。
- 若剩下的每一块都没有空位，状态变成死局，并写出是哪一种形状放不下。可以撤销或重开。
- 第一关有开局说明和一次可撤销的演示。另外三关是固定牌序：锚点两边、一手三块接右潮、窄港。

桌面可用鼠标；`U` 撤销，`R` 重开，`1`–`3` 选手牌，焦点不在按钮上时 `Enter` 涨潮。手机用点按。

## 四关

| 关 | 潮汐 | 手牌 | 一组能过关的摆法 |
| --- | --- | --- | --- |
| 第一潮 | 左 | 竖二 | 底部两行的右缘 `(4,5)`，六块挤成第 1 列 |
| 锚点两边 | 右 | 横二 | 锚点右侧 `(5,3)`。放在锚点左侧 `(5,0)` 能摆下，但挤不进第 6 列 |
| 一手三块 | 左，然后右 | 单点、单点、竖二；下一手两根竖三 | 先盖住第 3–6 行，再让两根竖三盖住全部六行 |
| 窄港 | 左 | 横三、单点 | 单点放在 `(4,5)`，横三放在 `(5,1)`。单点若先占底行 `(5,1)` 到 `(5,3)`，横三无处可放 |

坐标从 0 开始，第 0 行在最上，第 0 列在最左。

## 和选题说明的差别

- 操作是点选再点格，不是拖放。
- 消的是挤齐之后排满的行和列。只做横向挤齐时，同一行的块数不会变，所以潮汐真正凑出来的是列；锚点用来让块停在不同的列。
- 没有可随身携带的锚点库存。锚点写在关卡里。多一个可放置的锚点道具不会让这四关出现新的选择。
- 牌序是固定的四关，没有随机关，也没有广告、账号或服务器。

首页列表在根目录的 `games.json`。这个目录自己能通过 Pages 打开；把入口加进首页需要改共享清单，不包含在本目录里。
