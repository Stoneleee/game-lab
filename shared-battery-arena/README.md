# 共用电池球场

俯视二维小球场。蓝方和橙方把白球踢进对方球门。冲刺和大力射门花的是**同一块**电池：你加速，对手剩下的电也变少，电量条只有一根。

这是单机可玩灰盒。对电脑，或同一台设备上的本地双人。它不验证联网匹配、延迟同步或在线市场。

没有构建步骤。GitHub Pages 直接发布这个目录。

## 玩法

仓库根目录：

```bash
python3 -m http.server 8000
```

打开 `http://127.0.0.1:8000/shared-battery-arena/`。

- 先到 3 分，或 70 秒后比分高的一方获胜。平局就写平局。
- 移动：桌面对电脑时用 WASD 或方向键；本地双人时蓝方 WASD、橙方方向键。手机用摇杆。
- 冲刺：Shift（本地双人橙方是右 Shift 或 K），或按住「冲刺」。必须在移动时才耗电。每有一方冲刺，每秒扣 36；两边同时冲刺就是每秒 72。有人正在冲刺时不回充。
- 松手后每秒回充 20，上限 100。电量到 0 后，要回到 16，双方才又能冲刺。没人能在 0 附近蹭出冲刺速度。
- 踢球：空格（橙方 L）或「踢球」。贴着球且电量至少 18 时，大力射门并扣 18。不够就只轻轻碰，不扣电。
- 进球后双方回到开球位置，速度清零，**电池保留**。暂停期间不能趁机耗电或回充。
- 重开（按钮或 R）会同时清掉比分、时间、电池和速度。不会留下上一局的惯性。
- M 或「静音」关闭合成音。声音不出网，也没有音频文件。

教程会让你先移动、再看见电池下降、再踢一次球。可以跳过。

## 检查

规则测试不需要安装依赖：

```bash
node --test shared-battery-arena/sim.test.js
```

浏览器冒烟使用仓库根目录已有的 Playwright，不放进这个目录的运行时：

```bash
npm ci
npx playwright install chromium
node shared-battery-arena/browser-smoke.js
```

## 和设计说明的差别

- 做成俯视二维，而不是三维小车。加速是摇杆方向上的街机加速，不是转向、油门分离的车辆模型。
- 对手是按同一套物理出输入的脚本，不是真人，也不是服务器权威同步。本地双人只是左右两套按键。
- 进球不把电池加满，避免领先方独占下一球的速度；电池到 0 时两边一起变慢，所以花光电不会变成滚雪球。
- 耗尽后要回到 16 才能再冲，是为了不让电量在 0 附近一帧花、一帧充。
- 大力射门先扣 18，再扣这一帧的冲刺。站着按住冲刺不耗电，因为没有在推进。
- 页面故意没有写进根目录 `games.json` 和 `index.html`。试玩入口由上层统一加。
