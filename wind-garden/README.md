# 风吹小花园

转动风机，让风把种子送到格子上。花不挡风。灌木会挡住直线，风优先顺时针改向，下一粒种子就走新的路。

这一页是静态文件，没有构建。GitHub Pages 会直接提供 `wind-garden/`。

## 玩法

- 点一台风机选中它，再点一次，或点「转向」，顺时针转 90°。风机上的数字是这阵风能走的格数。
- 选花籽或灌木籽。亮圈是这一粒会落下的地方，蓝线是它要走的路。
- 「播种」之后种子才离开。花朵不改变风路。灌木会让经过它前面的风改道。
- 点一株植物再点「回收」，或再点它一次，种子回到手里，风路恢复。
- 「撤销」退回上一步，包括转向、播种、回收和重来。「重来」回到这座园的开头，也可以再撤销。
- 花床是软目标：顺风花床和灌木改道希望有一朵花；两条花床开一床即可，两床都开会另外标出来。自由园没有必须完成的目标。
- 音效默认关闭。打开后也只有几声短音，没有外链音频。
- 进度写在这台设备的 `localStorage`（`wind-garden-save-v1`），不登录，也不上传。

桌面可以用鼠标。手机单指点按。键盘：`Q` 转向，`1`/`2` 选种子，`Enter` 播种，`U` 撤销，`Backspace` 回收，`R` 重来，`M` 音效，`Esc` 关闭选园。

## 规则

每台风机吹出一条风。从风机出发，每进入一格花费 1 点风力。

- 花：风照直穿过。
- 灌木、石头、另一台风机：不能进入。风在前一格先试顺时针；那边出界或仍被挡，就试逆时针；两边都不通，种子停在当前格。
- 风力用尽，或再走就要出界时，种子落下。泥土和花床可以生根。风机上不能生根。落点已有植物时，这粒种不下，也不扣种子。
- 转弯不额外扣风力。同一位置和方向若重复出现，风停住，避免打转。

坐标 x 向东、y 向南，和画面一致。同一座园、同一操作，落点永远相同。

## 本地

在仓库根目录：

```bash
python3 -m http.server 8000
```

打开 `http://127.0.0.1:8000/wind-garden/`。

规则测试不需要额外安装：

```bash
node --test wind-garden/sim.test.js wind-garden/session.test.js
```

浏览器烟测使用仓库根目录已有的 Playwright，不往本目录加依赖：

```bash
npm ci
npx playwright install chromium
node wind-garden/browser-smoke.js
```

## 四座园

| 园 | 想看的因果 |
| --- | --- |
| 顺风花床 | 风机起初朝北，转到朝东后，花籽正好落在花床。若先种灌木，下一粒会改道。 |
| 灌木改道 | 左风机朝东把灌木种在 `(4,2)`。上风机转到朝南后，风被这株灌木挡住并改向西，花落到 `(0,1)`。先种花则上风机仍然直行，到不了花床。 |
| 两条花床 | 左小风机的灌木把主风带去 `(1,5)`，右小风机的灌木带去 `(3,5)`。两株都在时，先遇到的那株决定落点；回收上游灌木才能改去另一床。 |
| 自由园 | 左右两台风机对吹。没有过关。植物和方向会留在本地。 |

## 和设计稿的差别

- 风是每台风机一条可数的格点风路，不是流体，也不会合成一股。这样落点可以在播种前看清。
- 只有花籽和灌木籽。花满足花床，灌木负责改风。
- 风机位置和风力是固定的，只能转向，不能拖动或改风力。
- 目标不失败、不限时、不扣已落地的种子。种错了用撤销或回收。
- 广告、账号、服务器、外部请求都没有。音效是现场合成的。
- 试玩列表（根目录 `games.json` / `index.html`）留给统一入口，本目录不改它。
