# 热力小食堂

一口 4×4 的共享热锅。底火印在格子上。上下左右挨着的菜平分这些格子的底火；锅里每多一份菜，大家分到的热都变少，冷格上的菜也算。保温台才真正让出锅。空格会留一阵余温，下一份菜放上去会更热。

本目录就是页面，没有构建步骤。试玩页不在仓库根上挂链接。

## 玩法

- 点一种食材，再点格子，或者直接拖上去。选中的菜会浮起，熟度写在菜的上方。
- 格子上的数字是底火。选中食材时，空格会预告 `+每拍`，旁边的 `↓` / `↑` 表示这一手会让锅里的菜变慢或变快。
- 熟度：生、熟了（+2）、正好（+3）、过火（+1）、糊了（+0）。生的端不走。不是这单的菜会退回。
- 鸡蛋和青菜比面饼容易糊。可以挪到冷格停火，或放上只有一格的保温台。
- 一班四单：面饼；鸡蛋 + 面饼；青菜 + 鸡蛋；面饼 + 青菜。客人走了只少得分，班次会继续。目标 12 分，满分 21。
- 教学可以跳过。暂停会停住热。班次中重来要按两次。结算后可以再来一班，或再看教学。重开会清空菜、余温、分数和订单。
- 音效默认关闭。按「音效」才出声，再按「静音」关掉。没有音频文件。

## 和设计稿的差别

- 热是离散拍，不是流体。相邻组平分底火，再用「锅里有几份菜」缩小每一份。斜角不算相邻。
- 生的端出去会退回，不记 0 分；糊了端出去记 0 分并拿走。
- 保温台是一格，不加热，也不再分走火力。设计稿里的「腾锅」落在这里和出餐上。
- 不做广告、商店、员工、库存付费、剧情和多家餐厅。失败是这一班分数不够，不是中途游戏结束。
- 没有单步撤销。重来或再来一班会整班重置。
